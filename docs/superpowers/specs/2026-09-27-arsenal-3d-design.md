# Трёхмерный боец и оружие в арсенале

Дата: 2026-09-27 · Статус: согласовано пользователем

Цель: в арсенале вместо плоского портрета — трёхмерный боец в стойке с
оружием, который медленно вращается; все стволы арсенала — объёмные модели.
Выглядит как современная стилизованная 3D-игра.

## Решения

| Вопрос | Решение |
|---|---|
| Откуда модель | Своя: собирается кодом из объёмных деталей. Чужих моделей и лицензий нет, броня и оружие меняются от покупок |
| Где 3D-оружие | В руках бойца и превью на каждой карточке ствола в каталоге. Бой не меняется |
| Оптика | Без брони — тепловизор; кевлар, кевлар со шлемом, штурмовой, тяжёлый, сапёрный — квадрокуляр на 4 зелёные линзы |
| Сапёрный костюм | Заметно детальнее остальных |
| Лицо | Закрыто маской |

## Устройство

Игра остаётся одним файлом без зависимостей. Новый блок `3D В АРСЕНАЛЕ`:

- **Математика** — матрицы 4×4: перспектива, вид, перенос, поворот, масштаб.
- **Построители сеток** — скруглённая коробка, цилиндр (с фаской), капсула,
  сфера, тор, тело вращения, выдавленный профиль. Каждая деталь несёт
  материал; сетка — позиции, нормали, материал, запечённое затенение.
- **Сборка** — `buildSoldier(look)` и `buildGun(wid)` возвращают списки
  деталей `{ mesh, matrix, material }`. Чистые функции без WebGL —
  проверяются тестами в node.
- **Рендер** — WebGL1, один шейдер: ключевой тёплый свет, синий контровой,
  отражённый от пола, блики по Блинну — Фонгу, френель-подсветка кромок,
  самосвечение, процедурные текстуры по материалу. Ореолы линз —
  аддитивные спрайты. Тень под ногами и отражение на подиуме.
- **Материалы и текстуры** (считаются в шейдере): ткань с переплетением и
  потёртостями, кордура с ячейками MOLLE, полимер с зерном, воронёный металл
  с потёртыми кромками, дерево с волокнами, резина, стекло линз, светящийся
  люминофор, германий тепловизора.
- **Анимация** — оборот за ~12 с, дыхание; мышью (и пальцем) крутится вручную.
- **Каталог** — превью ствола рендерится тем же движком во внеэкранный
  холст и копируется в холст карточки; поворачивается, пока экран открыт.
- **Запас** — нет WebGL: остаётся нынешний плоский портрет, карточки без
  превью. Арсенал не ломается.

## Тесты

- Сетки: число вершин кратно треугольникам, нормали единичные, индексы в
  пределах.
- `soldierLook`/сборка: у каждого вида брони свой набор деталей; линз
  ночного видения ровно 4 у всех, кроме бойца без брони (у него тепловизор);
  у сапёрного деталей заметно больше, чем у тяжёлого.
- Все 20 стволов собираются, у снайперских есть прицел, у дробовиков — помпа.
- Без WebGL арсенал открывается и рисует запасной портрет.
- Глазами: снимки из браузера без окна (Playwright + Chromium), боец с
  четырёх сторон в каждой броне, лист всех стволов.

## Чего нет

Трёхмерного боя, анимации ходьбы, чужих моделей, изменений логики игры.
